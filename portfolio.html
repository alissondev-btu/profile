Meu Portfólio

Nesta página estão alguns dos projetos desenvolvidos durante meus estudos em Desenvolvimento de Sistemas. Os trabalhos envolvem desenvolvimento web, aplicações back-end, análise de dados e aprendizado de máquina, representando diferentes etapas da minha trajetória de aprendizado.

Perfil Mobile

Interface mobile desenvolvida para exibição de informações do usuário, apresentando nome, nickname, e-mail e status de perfil.

Turismo em Botucatu

Site informativo criado para divulgar atrações turísticas, hotéis, restaurantes, transporte público, prefeitura e serviços úteis do município.

Teste de Responsividade

Projeto desenvolvido com Bootstrap para demonstrar a adaptação automática dos elementos da página em diferentes tamanhos de tela.

Conversor de Moedas

Aplicação desenvolvida em Java Spring Boot que converte valores em reais para diferentes moedas internacionais.

Sistema de Login

Sistema de autenticação desenvolvido em Java Spring Boot, exibindo confirmação de acesso após validação das credenciais.

Machine Learning para Energia Solar

Projeto de aprendizado de máquina utilizando Python, Pandas, Scikit-Learn e Matplotlib para análise e modelagem de dados relacionados à geração de energia solar.

Análise de Turbina Eólica

Análise exploratória de dados relacionando velocidade do vento (m/s) com a potência gerada (Active Power kW), permitindo visualizar padrões de desempenho da turbina.
